# Real male Gold head library

The ready-to-use library contains **85 real heads** in `../public/player-faces/gold/`. The app installs its local embedded bundle automatically. Open Clubs to generate a team or use Random Real Face. No pack import or external request is required.

See `public/player-faces/gold/manifest.json` and `credits.html` for each original source, creator and licence. These are real photograph crops, with no synthesized faces. Existing assignments stay saved; the optional Replace Generated Faces With Real Faces button protects manually created/uploaded faces and already-valid real heads.

You may still use Clubs → Import Face Pack / Import Face Pack folder for additional licensed male Gold head images. JSON entries declare male/gold/head; individual image imports use your selection as the label. Prefer head crops rather than cards, badges or managers. Importing adds to the pool without rerolling players.
